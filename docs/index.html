INSTALL

نصب در کمتر از یک دقیقه

نیازی به دسترسی ادمین نیست؛ برنامه فقط برای کاربر فعلی نصب می‌شود.

  1. دانلود

    فایل LanguageFlagPopUp_Setup.exe را از دکمه‌ی بالای صفحه بگیرید.

  2. نصب

    اجرایش کنید. اگر می‌خواهید با ویندوز بالا بیاید، گزینه‌ی اجرای خودکار را روشن بگذارید.

  3. تنظیم

    از آیکون System Tray وارد Settings شوید، حالت نمایش و انیمیشن را انتخاب کنید و Apply بزنید.

# اجرا از سورس (Python 3.9+)
python -m pip install -r requirements.txt
python language_flag_popup.pyw --settings

# ساخت فایل اجرایی
pyinstaller --clean language_flag_popup.spec
