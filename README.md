
# 🏳️‍🌈 برنامه نمایش پرچم یا نام زبان (Language Flag Popup)

این برنامه یک ابزار سبک و مفید برای نمایش **پرچم کشور یا متن زبان فعلی کیبورد** در ویندوز است.  
هر زمان زبان کیبورد تغییر کند (مثلاً از فارسی به انگلیسی یا برعکس)، برنامه به‌صورت خودکار **پرچم یا متن زبان مربوطه** را روی تمام مانیتورها نمایش می‌دهد.

![demo](demo.gif "demo")

---

## ✨ ویژگی‌ها

- 🇮🇷🇺🇸 **نمایش پرچم یا متن زبان**
  - پرچم ایران برای فارسی (`0x429`)
  - پرچم آمریکا برای انگلیسی (`0x409`)
  - یا نمایش متن "FA / EN" در حالت متنی
- 💫 **انیمیشن محو شدن (Fade In / Out)** هنگام نمایش و ناپدید شدن
- 🖥️ **پشتیبانی از چند مانیتور**
- 🧠 **تشخیص هوشمند تغییر زبان** (بدون نمایش مکرر یا خطا)
- ⚙️ **پنجره تنظیمات پیشرفته**
  - انتخاب حالت نمایش: پرچم یا متن
  - تنظیم اندازه پرچم یا فونت
  - مدت زمان نمایش و سرعت انیمیشن
  - فعال یا غیرفعال کردن حالت Debug
- 🪟 **آیکون در System Tray**
  - دسترسی سریع به تنظیمات و خروج از برنامه
- 🪶 سبک، سریع و بدون نیاز به منابع زیاد سیستم

---

## 📦 پیش‌نیازها

- سیستم‌عامل: **Windows**
- نسخه پایتون: **3.7 یا بالاتر** (در صورت اجرای فایل `.pyw`)
- کتابخانه‌های مورد نیاز:
```bash
  pip install Pillow screeninfo pystray
````

* یا استفاده از فایل اجرایی مستقل (`.exe`) — بدون نیاز به نصب پایتون

---

## 🚀 نصب و راه‌اندازی

### گزینه 1: استفاده از فایل نصب‌کننده

1. فایل `LanguageFlagPopUp_Setup.exe` را اجرا کنید.
2. مراحل نصب را دنبال کنید.
3. برنامه به‌صورت خودکار در System Tray اجرا می‌شود.

### گزینه 2: استفاده از فایل اجرایی مستقل

1. وارد پوشه `dist` شوید.
2. فایل `language_flag_popup.exe` را اجرا کنید.

### گزینه 3: اجرای مستقیم کد پایتون

1. نصب پیش‌نیازها:

   ```bash
   pip install Pillow screeninfo pystray
   ```
2. اجرای برنامه:

   ```bash
   python language_flag_popup.pyw
   ```

## 🧭 نحوه استفاده

1. برنامه را اجرا کنید (از یکی از روش‌های بالا).
2. با تغییر زبان کیبورد (مثل `Alt + Shift` یا `Win + Space`) پرچم یا متن زبان فعلی نمایش داده می‌شود.
3. برای باز کردن تنظیمات یا خروج از برنامه:

   * روی **آیکون برنامه در System Tray** راست‌کلیک کنید.
4. برای بستن برنامه، از گزینه‌ی **Exit** استفاده کنید.

## ⚙️ تنظیمات برنامه

از طریق پنجره تنظیمات می‌توانید مقادیر زیر را تغییر دهید:

| گزینه                          | توضیح                                        |
| ------------------------------ | -------------------------------------------- |
| **Display Mode**               | انتخاب حالت نمایش: پرچم (Flag) یا متن (Text) |
| **Font Size**                  | اندازه فونت در حالت متنی                     |
| **Flag Width (% of screen)**   | اندازه پرچم نسبت به عرض مانیتور              |
| **Display Duration (seconds)** | مدت زمان نمایش پرچم یا متن                   |
| **Animation Duration (ms)**    | زمان انیمیشن محو شدن                         |
| **Animation Steps**            | تعداد مراحل انیمیشن                          |
| **Debug Mode**                 | فعال کردن چاپ پیام‌های خطا و لاگ در کنسول    |

> ⚠️ تغییرات پس از ذخیره، بلافاصله اعمال می‌شوند و نیاز به راه‌اندازی مجدد برنامه نیست.

## 🧰 ساخت فایل اجرایی جدید

برای ساخت نسخه‌ی اجرایی (EXE):

1. نصب PyInstaller:

   ```bash
   pip install pyinstaller
   ```
2. اجرای دستور زیر در پوشه اصلی:

   ```bash
   pyinstaller language_flag_popup.spec
   ```
3. فایل خروجی در مسیر `dist/language_flag_popup.exe` ایجاد می‌شود.

## 🧩 نکات مهم

* تصاویر پرچم در مسیر `images` باید با فرمت `.png` باشند.
* برای افزودن زبان جدید:

  * پرچم آن را در پوشه `images` قرار دهید.
  * کلید زبان (`lang_id`) و مسیر پرچم را به دیکشنری `FLAG_IMAGES` اضافه کنید.
* در صورت بروز خطا در اجرای برنامه، فایل‌های پوشه `build` را حذف کرده و مجدداً فایل اجرایی بسازید.
