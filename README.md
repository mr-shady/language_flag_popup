برنامه نمایش پرچم زبان (Language Flag Popup)
این برنامه یک ابزار ساده و سبک برای نمایش پرچم کشور مرتبط با زبان ورودی فعلی کیبورد در ویندوز است. با تغییر زبان کیبورد (مثلاً از فارسی به انگلیسی یا بالعکس)، پرچم مربوطه به صورت پاپ‌آپ روی تمام مانیتورهای متصل نمایش داده می‌شود. این برنامه به ویژه برای کاربرانی که مرتباً بین زبان‌های مختلف جابه‌جا می‌شوند مفید است.
ویژگی‌ها

نمایش پرچم زبان: نمایش پرچم ایران برای زبان فارسی (0x429) و پرچم آمریکا برای زبان انگلیسی (0x409).
انیمیشن محو شدن: نمایش پرچم با افکت محو شدن (fade-in/fade-out) برای تجربه کاربری بهتر.
پشتیبانی از چند مانیتور: پرچم به صورت همزمان روی تمام مانیتورها نمایش داده می‌شود.
تشخیص هوشمند تغییر زبان: جلوگیری از نمایش مکرر پرچم هنگام تغییرات سریع و ناپایدار زبان.
سبک و کم‌حجم: استفاده از منابع سیستمی حداقل.

پیش‌نیازها

سیستم‌عامل: ویندوز
پایتون 3.7 یا بالاتر (برای اجرای فایل .pyw)
کتابخانه‌های مورد نیاز:
Pillow (برای پردازش تصاویر)
screeninfo (برای شناسایی مانیتورها)


یا استفاده از فایل اجرایی .exe یا نصب‌کننده (بدون نیاز به نصب پایتون)

نصب و راه‌اندازی
گزینه 1: استفاده از فایل نصب

فایل LanguageFlagPopUp_Setup.exe را از پوشه اصلی اجرا کنید.
مراحل نصب را دنبال کنید.
پس از نصب، برنامه به صورت خودکار در پس‌زمینه اجرا می‌شود.

گزینه 2: استفاده از فایل اجرایی

به پوشه dist بروید.
فایل language_flag_popup.exe را اجرا کنید.

گزینه 3: اجرای کد منبع

اطمینان حاصل کنید که پایتون و کتابخانه‌های مورد نیاز نصب شده‌اند:pip install Pillow screeninfo


فایل language_flag_popup.pyw را اجرا کنید:python language_flag_popup.pyw



ساختار فایل‌ها
|   commands.txt                  # دستورات استفاده‌شده برای ساخت
|   icon.ico                      # آیکون برنامه
|   installer_script.iss          # اسکریپت Inno Setup برای ساخت نصب‌کننده
|   LanguageFlagPopUp_Setup.exe   # فایل نصب‌کننده
|   language_flag_popup.pyw       # کد منبع پایتون
|   language_flag_popup.spec      # تنظیمات PyInstaller
|
+---build
|   \---language_flag_popup      # فایل‌های موقت تولیدشده توسط PyInstaller
|
+---dist
|       language_flag_popup.exe  # فایل اجرایی مستقل
|
\---images
        iran.png                # تصویر پرچم ایران
        usa.png                 # تصویر پرچم آمریکا

استفاده

برنامه را اجرا کنید (از یکی از روش‌های بالا).
با تغییر زبان کیبورد (مثلاً با Alt+Shift یا Win+Space)، پرچم زبان فعلی به صورت پاپ‌آپ نمایش داده می‌شود.
برای خروج، پنجره کنسول را ببندید یا فرآیند برنامه را متوقف کنید.

تنظیمات
می‌توانید تنظیمات زیر را در فایل language_flag_popup.pyw تغییر دهید:

SHOW_TIME: مدت زمان نمایش پرچم (به ثانیه).
SCREEN_WIDTH_PERCENT: درصد عرض صفحه برای اندازه پرچم.
ANIMATION_DURATION: مدت زمان انیمیشن محو شدن.
ANIMATION_STEPS: تعداد مراحل انیمیشن.

ساخت فایل اجرایی
برای ساخت فایل اجرایی یا نصب‌کننده جدید:

نصب PyInstaller:pip install pyinstaller


اجرای دستور زیر در پوشه اصلی:pyinstaller language_flag_popup.spec


برای ساخت نصب‌کننده، فایل installer_script.iss را با Inno Setup اجرا کنید.

نکات

تصاویر پرچم در پوشه images باید با فرمت .png باشند.
برنامه به صورت پیش‌فرض از پرچم‌های ایران و آمریکا پشتیبانی می‌کند. برای افزودن زبان‌های دیگر، مسیر تصاویر جدید را به FLAG_IMAGES در کد اضافه کنید.
در صورت بروز مشکل، فایل‌های موقت در پوشه build را حذف کنید و دوباره فایل اجرایی را بسازید.
